まだ海図にない航路を。

エレツ株式会社は、北九州・小倉南区から数えきれない航路を走らせています。福祉、KUROFUNEMAN PROJECT、デザイン／コンサル、そして衣食住。現場で磨いた力を、次の海へ。

航路

計器に映る点の数だけ、事業があります。大きく分けると4つの海です。

  • 045°

    福祉

    黒船デイサービス・白船デイサービスと、暮らしの拠点 KUROFUNE BASE。 船団を見る　食卓を見る

  • 135°

    KUROFUNEMAN PROJECT

    企画。イベント、キャラクター、制作。北九州のヒーロー クロフネマンを軸に。 クロフネマン公式

  • 225°

    デザイン／コンサル

    ホームページなどのウェブデザイン、ロゴや印刷物のデザイン。経営の相談から M&A の交渉まで、AI と発信も。自社で動かしてきた仕組みを、あなたの会社へ。

  • 315°

    衣食住

    着る、食べる、住まう。衣は、服づくりと特別な衣装のデザイン。クロフネマンのロングコートや特殊部隊の衣装、クルー（隊員）たちの制服も手がけています。住まいは、エレツが管理する賃貸の基地 KUROFUNE BASE と、グループの不動産会社 HEADS株式会社が運営するハウスドゥ 福津。 KUROFUNE BASE を見る　ハウスドゥ 福津

そこは、住まいではなく「基地」。

基地とは、あなたの活動の拠点となる場所。楽しい仲間と過ごす空間と、プライベートな空間をあわせ持つ、新しいリゾートの住まいです。

屋上には、黒船を象徴する名物「クロフネ砲」と、開放的なジャグジーバス。グラスを傾けながら、あなただけの星空を。ひとときの癒しが、明日の活動をさらに加速させます。
